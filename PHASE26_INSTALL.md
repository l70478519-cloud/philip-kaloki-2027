# Phase 26 — Albums, Image Fitting & Functional Links

Changes:
- Homepage slideshow images now use contain-fit so the whole photograph remains visible inside the frame.
- Admin slideshow cards also show the complete image instead of aggressive cropping.
- Media page is now album-style instead of a long wall of thumbnails.
- Clicking the campaign album opens an in-page slideshow/lightbox.
- Album viewer supports previous/next, keyboard Left/Right, Escape, and a thumbnail filmstrip.
- Full-view album images use contain-fit so portraits and landscape images are not cut off.
- Header/footer phone and email are clickable `tel:` / `mailto:` links.
- Contact phone and email cards are clickable.
- Existing navigation, social, resource and CTA links remain clickable.

No new Supabase migration is required.
